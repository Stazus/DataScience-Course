# Lekcja 03 – Git i GitHub

Kurs: Data Scientist – LearnIT

## Cel lekcji

Praktyczne poznanie systemu kontroli wersji Git,
platformy GitHub oraz narzędzi wspierających
pracę zespołową i projekty Data Science.

W ramach lekcji wykonano 20 zadań praktycznych.

## Zadania 1–10 – Podstawy Git i GitHub

1. Utworzenie pierwszego repozytorium Git.
2. Podstawowe operacje na plikach i commitach.
3. Rozbudowa dokumentacji projektu.
4. Dodanie modułu wczytywania danych.
5. Praca z historią zmian Git.
6. Synchronizacja lokalnego repozytorium z GitHub.
7. Edycja dokumentacji bezpośrednio na GitHub.
8. Porównywanie zmian za pomocą git diff.
9. Git Flow – gałęzie feature, develop i main.
10. Rozwiązywanie konfliktów podczas scalania gałęzi.

## Zadania 11–20 – Zaawansowane Git i GitHub

11. Praca z remote branches – synchronizacja zmian między dwoma klonami repozytorium.
12. Pull Request przez GitHub – code review i scalanie zmian.
13. Kompletny projekt ML z Git Flow – gałęzie, Pull Requests i release v1.0.
14. Git Squash – łączenie commitów.
15. GitHub Actions – automatyzacja CI.
16. Monorepo – organizacja wielu projektów.
17. Git Hooks – automatyzacja kontroli kodu.
18. Git Cherry-pick i Git Stash.
19. GitHub Projects – tablica Kanban.
20. DVC – wersjonowanie dużych zbiorów danych.
