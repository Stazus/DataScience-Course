# Sales Analysis – Projekt analizy sprzedaży

## Opis projektu

Projekt edukacyjny realizowany w ramach kursu Data Science (LearnIT), lekcja 2, zadanie 5.

Celem projektu jest przygotowanie uporządkowanego środowiska do analizy danych sprzedażowych z wykorzystaniem języka Python.

## Cele projektu

- Wczytywanie i weryfikacja danych sprzedażowych.
- Czyszczenie i przygotowywanie danych do analizy.
- Analiza trendów sprzedaży i wyników finansowych.
- Tworzenie wykresów oraz raportów.
- Przygotowanie danych do przyszłego modelowania Machine Learning.

## Struktura katalogów

```text
sales_analysis/
├── data/
│   ├── raw/             # Surowe dane wejściowe
│   └── processed/       # Dane po przetworzeniu
├── notebooks/           # Notatniki Jupyter
├── src/                 # Kod źródłowy Python
├── models/              # Zapisane modele ML
├── reports/             # Raporty i wyniki analiz
├── .gitignore           # Reguły ignorowania plików przez Git
└── README.md            # Dokumentacja projektu
```

## Technologie

- Python
- pandas
- NumPy
- Jupyter Notebook
- Git i GitHub

## Organizacja danych

Surowe dane będą umieszczane w katalogu `data/raw/`, który jest ignorowany przez Git.

Przetworzone dane będą przechowywane w `data/processed/`.
